# 进阶看图刷词

从首页“开始看图刷词”或导航“看图刷词”进入；手机也可从“更多”进入。

## 词库与配图

独立整理1024个不重复词条：512个生活社交词、512个通用职场词。包含1008个不带连字符的单词及16个惯用连字符词。目标是成人进阶词汇，剔除常见小学初中基础词，不用原有IT词库凑数，也不把复数或不同词义重复计成新词。

每词配有一句自然情境例句、中文释义和所属词性。词表按256组相关含义组织，每组4词；认义时四个中文选项来自同组，顺序随机。核对后同时展示四个选项对应的英文，方便比较，而不是把完全同义的中文解释设成两个正确答案。

配图为24个原创成人生活及职场场景，按例句场景关联，同场景词可共用插画。图片来自两张本地插画图集，不是1024张各不相同的图片；已经转为WebP，总计约858KiB，运行时不调用外部图片接口。词汇模式按需加载，原学习页不用先下载完整词库或图片。

材料按实际使用场景编排，不冒称经过官方CEFR考试词表认证。具体词义针对当前例句，允许在后续验收中继续校订。

## 每轮流程

1. 选择生活、职场或全部词库，以及每轮10、20、30、50、100词；也可自定义5–100词。
2. 优先从尚未遇见的词里抽取；不足时补入已遇见词。同轮不重复，四个释义顺序保存，不因刷新改变。
3. 看图和英文例句，选择标出词的含义。核对后显示正确释义与同组词，点击下一词继续；重复点击不会重复计数。
4. 认义轮结束后明确询问是否把本轮全部词再拼一遍，可以开始拼写，也可以直接结束。
5. 拼写轮使用同一批词并重新随机顺序，隐藏英文目标词，保留中文提示、场景图和挖空例句；核对前不显示词条原文。支持列明的英美拼写变体、大小写和首尾空格。
6. 轮末分别显示认义与拼写成绩，可以回看本轮词汇、去复习错词或设置新一轮。

中途切换页面、刷新后重新进入，可继续当前轮次，并恢复当前拼写草稿。主动结束当前轮次需要页面内确认；已答词的遇见状态和错题保留。

## 记录与旧功能

只保存当前一轮的作答状态、当前草稿和已遇见词集合，下一轮替换上一轮；分类核对次数沿用原有累计摘要，不创建逐次作答时间线，也不增加学习分钟。遇见不等于已掌握，不自动修改原有自评掌握列表。

认义和拼写错题接入现有复习本，保留原题、选项或允许的拼写变体；原页再次答对或在错题本通过后，同步处理对应记录。认义题遵循选项规则，拼写题按词库原形与允许形式核对，不能由AI替代表达放宽。刷词流程本身不依赖AI接口。

## 验证

- `npm run audit:lessons` 增加1024词去重、256组四义、基础词排除、每个例句的唯一目标、24场景映射、本地图片尺寸、随机轮次与恢复状态检查。
- `npm run check:picture` 使用实际Pinia状态与数据，验证答题后的响应式锁定、重复与非法提交、同词拼写、跳过、续刷、优先新词、学习天数和存储异常。
- 浏览器覆盖自定义数量、认义错误与锁定、选项刷新稳定、轮末询问、目标词隐藏、拼写及草稿恢复、错题重做、词库范围、跳过、提前结束，以及390/320像素手机导航与布局。
- 原有课程、时态、阅读和巩固检查继续执行；新增模式不改写已有30天内容与历史进度。
