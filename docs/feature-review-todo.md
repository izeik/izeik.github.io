# 学习功能审查与 To-do List（历史提案）

状态：这是历史审查提案。用户后续选择及实施结果见 [巩固学习更新](learning-updates.md)；本清单不再代表当前实施范围。按当前源代码审查，不以旧验收记录代替当前实现。原有课程审查及 UI 修改保留；本轮不改程序、不 commit、不 push。

## 判断

已有的“按主题选词→文章例句→填空→自主表达”方向适合继续投入。当前更需要补齐“练习留痕→发现薄弱项→到期复习→换场景运用”的闭环，暂不优先扩充词库或增加学习页面数量。

以下是对功能设计和实现的判断，并非基于真实使用数据或学习效果实验；没有证据把任何模块断定为对你无用。

## 现有功能：哪些值得保留，哪些需要调整

## 待办清单

下列均未开始，优先级是建议，等待用户选择。规模“小/中/大”为相对实现范围，不是工期承诺。

### P0：先补齐学习记录与保护

- [ ] **T01 · 统一作答记录（中）**
  - 问题：各模块完成、错误和自评的记录方式不一致，每日填空缺少持久化历史。
  - 内容：记录课程、稳定题目 ID/内容版本、题型、首次作答、订正、是否使用提示、时间和判定来源；自主表达保存回答及修改版。不同题型采用各自的结果，不强行计算总正确率。
  - 验收：刷新后能查看本次记录；重复核对不重复计数；首次答错后订正不会被改写成首次答对；换日输入仍清空，复习历史仍保留。

- [ ] **T02 · 错题与待复习本，支持直接重做（中，依赖 T01）**
  - 问题：词汇和每日填空未统一入本，已有错误记录不能直接重练。
  - 内容：客观题确定错误自动收录；填空与参考不同先标“待确认/待复习”，避免把合理替代表达判成语法错误。保存原题、原答、解释与来源，提供“重做本题/返回课程”。
  - 验收：至少覆盖词汇、每日填空及阅读；相同错题合并并累计次数；AI 建议与教材判定分开显示；多次独立答对后可移出当前队列，但保留历史。

- [ ] **T03 · 学习数据导出与导入（中，可独立进行）**
  - 问题：换设备、清浏览器数据或换站点地址时，缺少可靠的迁移方式。
  - 内容：导出收藏、掌握记录、错误本、学习计划笔记和新增作答历史；标注备份版本。导入前预览及校验，允许明确选择合并或替换，并先保留导入前备份。不导出 API 密钥。
  - 验收：导出→新浏览器导入可还原记录；损坏文件不覆盖现有数据；同一备份重复导入不产生重复项。明确这是手动迁移，不冒称自动云同步。

### P1：真正帮助巩固与运用

- [ ] **T04 · 按实际学习日期生成到期复习（中，依赖 T01）**
  - 内容：在实际学过的词中安排复习，先采用易理解的 1/3/7 天间隔；根据回忆结果调整，优先薄弱词，覆盖已学的单词和短语，不再固定只取每课前四项。首页提供“今日待复习”，限制每日负担，允许延期。
  - 验收：直接学第 20 课也不会要求复习从未学过的第 19 课；跳课、跨天和多天未学后仍有合理队列；未做复习不自动视为完成。

- [ ] **T05 · 掌握程度分级与延迟检验（中，依赖 T01，宜与 T04 同期）**
  - 内容：区分“见过/能独立回忆/能在新句子里使用”，保留用户自评与练习证据的区别。旧“已掌握”记录迁移为自评标签，不当作已通过新测试。
  - 验收：看过答案后立即填对不直接升级为长期掌握；看中文回忆、隔日检验和换语境表达能分别记录。

- [ ] **T06 · 每日迁移任务：用今天的表达说自己的事（中）**
  - 内容：每课选择 2–3 个关联词条和 1 个语法点，完成一个贴近主题的新任务，例如改约时间或说明项目延期；可文字回答或口头自评，支持保存和改写。
  - 验收：任务对应当前课程，提示可逐步收起；展示表达目标与自查项，无 AI 配置也可做；完成计为练习，不未经评估就计为正确。AI 纠错可后续单独启用。

- [ ] **T07 · 基于课文的听写、分段重听与复述（中）**
  - 内容：先只听当天句子，再填关键词或完整短句；支持重听和显示原文，最后用自己的话总结。复用现有声音设置。
  - 验收：首次作答前不直接展示答案；能区分独立答对与揭晓后订正；记录听写回忆结果，不把识别文字或系统朗读当作发音评测。

- [ ] **T08 · 灵活每日计划（小至中）**
  - 内容：提供“10 分钟复习/25 分钟巩固/原 120 分钟深度学习”等可选计划；根据到期词和薄弱项生成少量明确任务。保留现有自由选课和长计划。
  - 验收：切换计划不丢笔记或已完成项；分钟标明建议用时；缩短时间仍保留回忆和输出，而不是只减阅读量。

### P2：有基础数据后再追加

- [ ] **T09 · 更有解释力的进步看板（中，依赖 T01/T04）**
  - 内容：显示完成的到期复习、独立回忆表现、反复出错的表达和待强化场景；将自评、客观题和 AI 建议分开。样本不足时显示“数据不足”。
  - 验收：不会把已看答案、重复点击或手动勾选包装成能力提升；不直接以不同难度题的正确率变化断言进步或退步。

- [ ] **T10 · 自己的录音回放与前后对比（中至大）**
  - 内容：在设备支持时记录自己的跟读，回放本人录音和示范声音；允许重录、删除和明确选择是否保存。
  - 验收：拒绝麦克风后仍可学习；录音不默认上传；可删除本地音频；提供设备兼容及容量提示，不生成未经验证的发音分数。

## 第一批建议审阅范围

推荐先选 **T01 + T02 + T03 + T04**：先知道“做过什么、哪里不会”，再决定“下次练什么”，同时保护已有记录。它们完成后，再用 T05/T06 加强从记忆到表达。

这批不建议同时做实时 AI 陪练、账号云同步或真人音频库：这些可以有价值，但需要额外服务、费用或内容维护，适合在核心巩固流程跑通后评估。排行榜、虚拟等级、更多打卡奖励也暂缓，优先看真实回忆和运用。

- `src/components/StudySession.vue`：按课次减 1/3/7 的复习、固定选词和两小时自主勾选。

- `src/components/views/VocabularyView.vue`：参考答案核对及操作时长记录；未统一接入错题。

- `src/stores/learning.ts`：本地持久化、手动掌握与估算分钟；未建立统一到期队列及用户数据迁移入口。
- `server/aiTutor.ts`、`src/components/GapFeedback.vue`：可选 AI 单题用词反馈及服务配置要求。
