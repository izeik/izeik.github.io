# 巩固学习与课文交互更新

## 本次按用户取舍完成

1. **移除学习分钟展示与新估算累计**：首页以待巩固题目替换分钟；统计改为薄弱题型、具体待巩固内容及重做表现；固定两小时计划改为不计时的六项学习步骤。旧笔记、勾选和已有数据保留，新操作不再增加估算分钟。文章故事本身出现的时间表达保留。
2. **选择题解析**：阅读理解全部作答并点击“检查理解”后，每题无论对错均有课程解析和“AI 解析本题”。主动点击才调用 AI，不在每次换选项时发请求。AI 收到题目、选项、所选答案、参考答案和原文，返回中文理由及原文依据；填空继续保留原来的 AI 用词解析。
3. **错题/待复习题直接重做**：阅读选择题保存原选项及语境，可在错误页原地重选；词汇、每日填空和阅读补全可重填。与填空参考不同先标待复习，不直接认定语法错误。重复问题合并；通过重做标为已通过，再次答错回到待复习。旧记录若没有原题，明确提示仅支持回忆推荐表达。
4. **30 个换场景表达任务**：每课一个不同的新情境，结合当天词汇与语法，提供自查清单。可自行改写，再自主确认完成；不自动打语言能力分。
5. **薄弱项和复习表现**：只保存题型核对总数、与参考一致次数、错题重做汇总、迁移任务完成标记；具体待复习内容来自错题本。包括订正与重复练习，不把它解释为首次正确率或掌握率。
6. **课文短语优先查义**：先匹配已收录的最长短语，再处理剩余单词；优先当天课程释义，支持常见动词词形，以及部分 pick him up 这类代词分隔形式。显示原文形式，查询对应词条；匹配到的短语作为一整个触碰目标显示释义，不拆成两个孤立词。未收录或复杂变体不保证识别，不声称完整的语义理解。
7. **朗读与查词分离**：每句前独立扬声器按钮，再次点击停止；播放中使用温和背景提示。词语悬停、键盘聚焦或点击查义，不触发整句朗读。查词不再依赖打开中文句译。

## 明确没有追加的功能

不建立逐次作答/订正流水，不增加学习计时器，也未实施学习数据导入导出。只有用户允许的错题保留原题与最近的错误表达，以便重做；迁移任务草稿不持久化，仅保存完成标记。页面离开前会提示自行保留想留下的句子。

原 feature-review-todo.md 是审查提案；本文件记录用户筛选后的实际实现。此前文档或截图中的两小时及分钟指标属于历史版本。

## 检查结果

- `npm run format:check`、`npm run audit:lessons`、`npm run check:reinforcement`、`npm run build` 均通过。
- 课程结构核验仍覆盖 30 天、600 个词条、180 道巩固填空。
- 新回归检查覆盖最长短语、边界、常见词形、代词分隔短语、30 个不同迁移任务、旧题结构校验；本地模拟 AI 上游验证选择题与填空两种协议，以及非法输入、错误响应和限流提示。
- 浏览器实测每日填空答错→待复习本→重做通过→分类汇总更新；刷新后重做结果保留，不产生逐次回答流水。
- 阅读选择题答对和答错均出现 AI 入口，模拟响应可显示解析；错误选择题可原地重选原选项。
- 旧错题、学习步骤勾选可继续使用，旧分钟总数在新练习后不再增长。新迁移任务草稿离开后不保存，完成标记保留。
- 朗读开始/停止、整篇停止和过期音频回调用模拟语音事件验证；真实音色与麦克风仍由设备提供。本次不做发音打分。
- 桌面、390px 和 320px 的短语弹层、查词不触发朗读、句译开关及横向布局检查通过。
- AI 未配置真实服务，未进行付费调用。已验证接口、模拟结果与未配置时的提示，真实模型的解释质量仍需用户原有配置验证；课程解析和参考核对不依赖 AI。
- Vite 仍有既有的大包体积提示，构建成功。
