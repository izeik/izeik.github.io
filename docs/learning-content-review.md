# 前 30 天学习内容审查记录（重编前）

本文件记录重编前版本。当前课程已按日常与通用职场对话目标重编，请以 [对话主线更新](conversation-course-update.md) 和最新逐日核验表为准。

## 结果与范围

以第一天的情境组织方式为参照，审查并调整第 1–30 天的 600 个词条、文章及对应句译、90 道阅读理解题，以及 180 道巩固填空。每天保留 20 个词条，现为 10–12 个单词、8–10 个短语；第一天本身也接受检查。

每课增加两个对应文章情节的词汇分组。首页展示单词/短语数量、分组标题和词义，便于先成组回忆，再到文章中复习。第 11–30 天移除偏离主线的第三段，重新选择核心故事中的词条，同时更换依赖旧段落的阅读题和句子补全题。第 1–10 天保留主要故事，修订选词或表达。

## 填空与记录

- 每天 6 道巩固填空：3 道词汇、2 道搭配、1 道语法，另保留阅读页原有句子补全。
- 从当天真实例句出题；无效候选继续寻找，避免重复题、答案在句中另一处出现，以及用 so 挖掉 Sofia 开头等边界错误。
- 核对忽略大小写、首尾空格、连续空格和直/弯单引号差异。
- 错误显示“待订正”，不再因点击核对就打勾；修改后可再核对。日内切题保留输入，换日重置。
- 保留旧 ID 与词条的对应关系。新词分配新 ID，两个退出日课的旧卡片仍留在词库，避免旧收藏和位置索引错位。
