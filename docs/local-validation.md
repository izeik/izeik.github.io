# 本地启动与验收

本副本已先保存到云端工作区，在云端独立干净副本完成安装、构建和浏览器验证。这里的 localhost 测试不是用户电脑上的验证。

## 在你的电脑运行

下载 ZIP 并解压到新目录，避免覆盖个人配置。安装 Node.js 20 或更新版本，在包含 package.json 的目录打开终端：

```bash
npm ci
npm run audit:lessons
npm run dev
```

打开终端给出的地址，通常为 http://localhost:5173/ 。检查生产版本：

```bash
npm run build
npm run preview
```

打开 preview 输出的地址。ZIP 不含 node_modules、Git 历史或个人 .env.local。可复制自己已有的 AI 配置；未配置时仍能使用参考答案核对。

## 建议验收

- 首页选第 1、4、9、15、24、30 天：每课 20 个词条，显示单词/短语数量和两个关联分组。
- 展开巩固填空：每课 6 题，可切题、核对、订正；错误不会显示已答对的勾。
- 答过一题后换日：从第一题开始，输入和核对状态为空。
- 从首页进入词汇、阅读、语法：对应当前学习日。
- 阅读时核对词条、例句、句译和理解题答案是否自然清楚。
- 在常用浏览器及窗口大小下检查长词组是否完整显示。

确认没有问题后，再在对话明确要求 push。当前不会自动上传到 Git 仓库。
