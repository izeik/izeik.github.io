# Everyday English · UI 改版

## 设计与页面

采用现代学习产品常见的课程封面、模块卡片、分步路线和移动端底部导航，重新组织原有页面。

- 视觉：暖白背景、深绿侧栏、浅鼠尾草绿封面与橘色主按钮。衬线英文标题搭配中文无衬线正文，统一卡片、间距、表单、焦点样式。
- 首页：课程选择、当前主题封面、开始学习入口、真实掌握进度、词汇关联分组、阅读与语法预览，以及四步学习路线。
- 学习计划：保留原两小时计划与全部记录，改为可展开区域，缩短初次进入首页的阅读路径。
- 阅读与词汇：增加英文词卡的视觉层次，调整阅读正文的字体、字号、行距与文章标题，保留跟读、译文、收藏及掌握功能。
- 手机：五个固定导航入口；“更多”打开包含八个模块的菜单。窄屏不依赖横向滑动导航，长词组自动换行。
- 不新增第三方依赖、远程字体或图片请求。封面装饰由本地 CSS 与已有图标组成。

学习统计直接来自现有记录。课程数据、LocalStorage 键、收藏和掌握记录均沿用已有实现。

## 验证

- 在独立运行副本中执行 `npm run format:check`、`npm run audit:lessons` 和 `npm run build`，均通过。课程核验仍覆盖 30 天、600 个词条及 180 道巩固填空。
- Chromium 检查 1440、1024、820、390、320px 五种宽度：八个模块导航、首页学习入口、课程切换、填空核对与重置、展开学习计划通过；无页面级横向溢出、无浏览器运行错误。
- 最终字号调整后再次检查 1440、390、320px 的阅读和词汇页，均通过。
- 开发服务与生产预览启动后检查首页及填空作答通过。以上是云端电脑上的运行验证；用户自己的电脑仍需按 local-validation.md 启动确认。
- 构建保留既有的前端包体积提示；本次没有调整词库加载和全量 Vuetify 注册策略。
