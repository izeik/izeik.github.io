# 功能逻辑修复

本次修复功能检查中发现的5处问题，统一原练习、错题本与学习统计的处理规则。

## 答案与错题判定

时态练习与错题本共用同一答案匹配函数，接受题目明确列出的否定缩写、英美拼写以及大小写、空格、弯引号差异。例如 `does not drink` 和 `doesn't drink` 都可通过；`does not drinks` 仍不能通过。选择题只核对正确选项，不因填空的替代表达规则放宽。

新错题保存允许的答案列表。旧时态错题在读取时按原句和参考答案恢复对应题目的允许形式；旧阅读补全记录补充其自然表达认可规则。既有收藏、进度、错题和历史分钟保留，课程版本不变。

## 订正与AI结果

在阅读、时态、每日填空或词汇页核对正确后，同步处理对应类型、原句和参考答案的错题。阅读理解选项订正也应用相同规则；保留原错题记录，标记为已订正通过，不删除其他待复习题。

错题页接收阅读补全的AI结果：`natural` 标记为AI认可通过，`possible`、`unsuitable` 继续待复习。指定时态题和选择题保留本题约束，AI解析不能代替规定答案的核对。切换错题会取消旧请求，旧结果不会更新新选题。

新的错误或重做失败会清除先前的通过来源，避免残留“AI已认可”等旧状态。AI认可更新错题状态，不额外增加一次核对计数；重做摘要仍统计实际提交时与课程允许答案相符的次数。

## 学习活动与词库顺序

核对每日巩固题和重做错题会记录当天学习活动。当天多次作答仍对应一个活动日期，不新增分钟估算，重复提交受原有按钮与状态保护。

完整词库的“下一个”沿当前收藏、分类、掌握及搜索结果前进；结果为空或仅有当前词时禁用。当前卡片不在筛选结果内时，从结果的第一词开始。每天20个核心词的课程仍按当天清单学习，到末词停止。

## 验证

- `npm run format:check`、`npm run audit:lessons`、`npm run check:reinforcement`、`npm run build`。
- 现有CI回归增加允许缩写、旧式单参考答案、非法答案元数据、严格时态和选择题的AI认可限制。
- 浏览器逐项复测5处问题；覆盖新旧错题与刷新恢复、缩写和英美拼写、单次与重复提交、零/一/多个筛选结果、课程末词、原题订正的题目隔离，以及AI自然/可能/不适用三类结果和迟到响应。
- 原有40篇阅读的三题完成条件、16组时态练习、手机布局和课程迁移继续回归。

AI交互以本地模拟响应验证状态逻辑，没有调用付费服务；线上AI解析仍依赖已配置的服务端接口。
