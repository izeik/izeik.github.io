## 范围与参照

## 内容验收标准

1. 每天恰好 20 个学习词条，同时包含单词和短语，避免全部为单词或全部为短语。不强制固定比例，以场景实用性为准。
2. 每天围绕清晰的生活或应用场景选词；词条之间形成有意义的搭配、动作链或语义关联，避免无关词汇拼凑。
3. 学习词条在当天文章中自然出现，允许合理词形变化；例句、译文及文章表达一致，不能只在词汇列表中标注关联。
4. 每天至少 4 道可实际作答的填空练习（“三个以上”），不是选择题。检查题目展示、答案判断、反馈和切换课程后的状态。
5. 填空围绕当天词汇、短语或语法，语境清楚，答案合理，避免重复凑数。

## 保存与验证顺序

1. 完成审查和修改，记录逐日结果，并将修改保存在云端工作区。
2. 准备本地运行所需的代码和说明，进行启动验证。云端运行不能冒称已在用户电脑验证。
3. 用户本地启动并确认没有问题后，等待用户明确要求，再 push 到 Git 仓库；当前不 push。
