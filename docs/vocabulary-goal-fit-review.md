# 词汇目标适配性审查（更新前记录）

本审查针对更新前版本。后续已按本结论重编课程，当前实现见 [对话主线更新](conversation-course-update.md)。以下数字和问题保留作审查依据，不代表当前课程状态。

## 结论

**部分符合，但还不能称为针对“尽快应付日常与通用工作对话”的最优选词。** 当前课程更接近日常阅读与软件开发、技术支持英语的组合。若工作涉及开发、产品或技术支持，专业部分有用；若工作主要是一般办公沟通，需要提高通用对话表达的优先级。

本次重新阅读了当前第 1–30 课的全部词条，并检查口语模块中的现有表达。没有修改课程数据或程序。

此前“词条和文章关联、每天混合单词与短语”的核验，验证的是内容组织及结构；它不能证明选词对口语目标最优，也不能保证学完一定能流利对话。

## 当前数据与主题分布

- 30 课合计 600 次词条呈现，按当前拼写形式去重为 511 项，不是 600 个全新独立词；不同词形仍可能属于同一个词。
- 按是否含空格统计为 308 个单词条目、292 个多词条目。多词条目中既有固定搭配，也有从文章选出的普通组合，不能全部视为常用固定短语。
- 重复出现 issue、request、release、account、customer、browser 等，反映技术与客户支持主题占有较大比重。重复本身可以帮助复习，关键是重复的内容是否符合实际交流需要。

## 哪些值得优先练

| 当前表达                                                  | 用途与理由                                                        |
| --------------------------------------------------------- | ----------------------------------------------------------------- |
| let me know、get back to you、keep you posted             | 告知、回复、跟进，生活和工作都能复用。                            |
| make sure、find out、deal with、figure it out             | 确认、查明和解决问题，跨场景使用范围较广。                        |
| take a break、by the way、to be honest、in that case      | 自然衔接对话、表达态度和回应情况。                                |
| ask for help / asking for help、follow-up questions       | 求助和追问，有助于把对话接下去；学习时应掌握可变形的表达。        |
| provide an update、reduce the scope、longer than expected | 汇报、协商任务与解释变化，对相关工作沟通有直接用途。              |
| before work、after lunch、twice a week、on the way        | 日程与安排表达。现在的 on his way 可扩展练 on my way 等人称变化。 |

日常的 morning、breakfast、coffee、station，以及工作的 meeting、schedule、deadline、feedback 等也值得保留。基础词配上可替换句型，才更容易用于对话。

## 哪些应降低初期优先级或改写呈现方式

1. **专业词集中度较高**：endpoint、payload、parameter、runtime、constant、connection pool、staging environment 等对相关技术工作有用；对通用寒暄、点餐、约时间、请求帮助和会议协商的直接帮助有限。更适合作为行业扩展，而非人人都要先掌握的口语核心。
2. **部分多词条目迁移性偏弱**：future code review、show that task、every feature、shared hour、needed discussion 等能帮助理解课文，但不都适合作为优先背诵的完整表达。应根据交际用途重新筛选。
3. **部分表达固定在故事形式**：walked the customer through the setup、writing down each expense、on his way 等本身可以成立，但学习卡应同时显示可套用形式，例如 walk someone through …、write down …、on my/your/the way，并保留原文词形作为例句。变成模板时，需要相应调整查词匹配和填空，不能只改显示文字。
4. **常见对话功能没有充分进入日课核心**：请求、澄清、确认理解、回应邀请、礼貌拒绝、改约、表达偏好、简短汇报与追问，应在多个主题中反复使用。当前口语模块已有其中不少内容，但还未系统贯穿前 30 天的核心选词。

## 建议优先串联的口语模板

以下是教学取舍建议，不是经语料库排名得出的“最高频”清单。部分已经存在于项目口语模块，可优先整合，不必重建词库。

- Could you help me with …? —— 请求帮助。
- Could you say that again? —— 没听清时请求重复。
- Do you mean …? —— 确认理解。
- I'd like … / I'm looking for … —— 说明需求。
- Would … work for you? / Could we … instead? —— 约时间及提出替代方案。
- I'm working on … / I've finished … —— 汇报进度。
- I'm having trouble with … —— 说明困难。
- I'll get back to you … —— 约定回复或跟进。

## 后续调整标准（本轮未实施）

- 保留每课 20 个词条、单词和短语混合、词条之间及与文章强关联的要求。
- 先由“今天要完成哪种对话”决定核心表达，再配文章，避免仅因出现在文章中就选为核心词。
- 可以试用“10 个实用单词 + 8 个可复用短语/句型 + 2 个行业扩展”的结构；这只是可讨论的选词框架，不是固定科学比例。行业扩展应根据真实工作内容选择。
- 日常和通用职场场景应贯穿整个月；技术场景可独立为扩展线，具体比重还取决于用户的工作类型。
- 每课增加一个使用核心表达的短对话，并在换场景任务里再次使用。20 个词条允许包含有意复现的核心表达，不要求每天都是新词。
- 核心验收应看能否在新情境下回应、追问及说明情况，而不只看词义或原文填空。

个人起点、听力理解和实际开口练习都会影响进展。选词能减少绕路，但单靠背完词表不能保证快速掌握对话。
