# 语法提示与独立时态练习

语法页的121个主题、首页当日语法卡及每日巩固中的语法题均展示时态与句型提示。桌面端提示放在造句任务旁，窄屏放在任务前。提示说明当前例句的时间关系、动词结构，以及迁移题是否换了时态；相关按钮可打开对应时态。

提示区分时态与句型：礼貌请求中的 could / would 不自动表示过去，Thanks for helping 中的 helping 是动名词，to deliver 是不定式，祈使句按指令结构处理。现在完成时的 for 说明改为结合当前时间关系判断，避免将时长词当成固定答案。

新增“英语时态”导航入口，手机从“更多”进入，也可从语法页打开。

- 12种主要时态：现在、过去、将来分别包含一般、进行、完成、完成进行。
- 4种过去将来形式作为进阶扩展，注明较少使用的形式和转述语境，并区分 would 的条件、礼貌等用法。
- 每组有中文用法、三类句式、时间线索、易错点、中英例句、朗读与关联时态对比链接；每组3道填空，共48题。
- 另有6道易混练习，默认隐藏提示，可手动打开；包含“主将从现”以及一般过去与现在完成的区别。
- 本地核对接受大小写、首尾或重复空格、已列明的常见否定缩写和英美拼写。结果依据本组目标形式，逐题显示原因，可修改和重新练习；无需AI服务。
- 错题保存原题与解释，可在错误记录重做，回到时态页订正也会处理对应记录。统计沿用累计摘要，不保存逐次答题流水，不增加分钟计时。

验证包括：16组内容与54题结构核验、121个主题提示覆盖、否定缩写、过去分词和时间从句回归；浏览器逐组核对48题、易混6题、独立反馈、清空、订正、错题记录，以及390/320像素手机导航和布局；保留原有课程、阅读和AI协议检查。
