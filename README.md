# Everyday English Trainer

面向中文母语者的日常与职场英语口语训练 MVP。使用 Vue 3、TypeScript、Vite、Vuetify 和 Pinia；学习进度使用浏览器 LocalStorage 保存，无需付费 API 或账号。

## 启动

需要 Node.js 20 或更新版本。

```bash
npm install
npm run dev
```

浏览器打开 Vite 输出的本地地址。生产构建：

```bash
npm run build
npm run preview
```

## 功能

- 学习首页：今日课程、待巩固题目、自评掌握数量和学习路线。
- 词语搭配：通用表达与可选 IT 职场词库，支持搜索、收藏、掌握标记、朗读和练习。
- 看图刷词：独立的1024词进阶词库（生活社交512词、通用职场512词），24个本地场景插画，例句与四个关联释义；可选每轮10/20/30/50/100词或自定义5–100词，刷完后可选择用同一批词再练拼写。支持续刷和错词重做，见[模式说明](docs/picture-drill.md)。
- 情景口语：日常问题以及职场、开发交流表达；可文字回答并查看示例。
- 语音训练：浏览器 SpeechRecognition（如支持）与 SpeechSynthesis；没有识别能力时保留文字输入，不提供虚构的发音评分。
- 语法：基础知识点、搭配与30天配套造句练习，121个主题均有直接可见的时态或句型提示；可跳到相应时态练习。
- 英语时态独立页：12种主要时态与4种过去将来扩展，每种含用法、肯定/否定/疑问结构、例句、易错点及3道填空；另有6道易混时态练习，共54题，支持逐题核对、订正和错题复习。
- 30 天学习路径：15 个日常场景与 15 个通用职场场景交替安排；每天 10 个单词、10 个口语搭配/句型、配套阅读和语法。
- 每课有 4 句可朗读、可遮挡角色的短对话，并在词汇卡显示可替换句型；专业技术词作为可选扩展。
- 每日词条按两个关联场景分组；每天另有 6 道巩固填空（3 道词汇、2 道搭配、1 道语法）。
- 阅读页每篇 3 道句子补全，覆盖 30 章及 10 篇扩展阅读；各题单独核对、订正和 AI 解析，三题通过后才可完成新的阅读记录。
- 错题与待复习本：保留原题并直接重做；分类薄弱项、重做表现和迁移任务完成数在本地汇总，不保存逐次作答流水。
- 原题订正与错题重做使用一致的允许答案；阅读补全获AI自然表达认可后同步更新错题状态。每日巩固计入学习天数，完整词库的下一词遵守收藏和搜索筛选。详见[功能逻辑修复说明](docs/functional-fixes.md)。

## 数据与限制

语音识别由浏览器实现，设备和浏览器支持不同；麦克风通常要求 localhost 或 HTTPS。所有练习数据只保存在当前浏览器的 LocalStorage 中，清理浏览器数据会一并清除学习记录。内容为初始学习材料，可继续扩充和校订。

## 项目结构

```text
src/
├── App.vue                    # 应用外壳、导航与活动页面切换
├── main.ts                    # Vue、Pinia、Vuetify 初始化
├── style.css                  # 全局基础样式与响应式规则
├── components/views/          # 各学习页面的独立视图组件
├── composables/useTrainer.ts  # 页面共享的练习状态与交互逻辑
├── data/
│   ├── expressions.ts         # 日常搭配学习卡片
│   ├── professionalVocabulary.ts # IT 与职场首批 386 条词汇
│   ├── conversation.ts        # 日常问题、职场与开发表达
│   ├── grammar.ts             # 语法知识点与练习
│   ├── grammarHints.ts        # 各语法主题的时态、情态或非谓语提示
│   ├── tenses.ts              # 16组时态讲解与54道练习
│   ├── lessons/               # 30 天逐日课程；每个 day-XX.ts 包含当日词汇、文章与语法
│   │   ├── shared.ts          # 日课类型、结构校验与练习字段补全
│   │   └── index.ts           # 汇总 30 个日课文件
│   ├── learningPlan.ts        # 汇总可自由选择的 30 天日课
│   └── content.ts             # 内容模块统一导出入口
└── stores/learning.ts         # Pinia 学习状态与 LocalStorage 持久化
```

## 格式与注释约定

课程核验：`npm run audit:lessons`。运行 `npm run audit:lessons -- --report` 可更新前 30 天逐日核验表。审查记录见 [当前课程说明](docs/conversation-course-update.md)，下载副本的运行步骤见 [本地验收说明](docs/local-validation.md)。

- 使用 Prettier 统一 Vue、TypeScript、CSS、JSON 和 Markdown 格式。运行 `npm run format` 格式化，运行 `npm run format:check` 检查格式。
- 页面模板放在 `components/views/`，跨页面共享的状态和动作放在 composable，持久化规则放在 store，学习材料放在 `data/`。
- 注释解释模块职责、数据来源或不明显的业务原因；避免重复描述变量名或模板本身已经表达的内容。
- 日课内容写入 `data/lessons/day-XX.ts`；每课固定保存 20 个词条、文章、文章直连词组 ID 与语法重点，调整日课时只需编辑对应日期文件。
- 通用词库、文章库和语法库仍作为独立素材库维护；日课内嵌其选定词组和文章副本，便于逐日修订而不影响其他页面。

## 每日巩固和 AI 用词解析

在首页选择学习日，展开“巩固填空”。核对参考答案后，点击“AI 解析我的用词”可判断替代答案是否自然，并查看理由、建议词和完整例句。词汇卡及阅读填空也有此入口。阅读填空接受教材答案，也接受 AI 判断在本句自然的替代表达。AI 建议调整的阅读填词会连同建议和理由记入错误本。

复制 `.env.example` 为项目根目录的 `.env.local`，填写兼容 Chat Completions 的配置：

- `AI_BASE_URL`：服务的 API 根地址，按服务商说明包含版本前缀，例如 `https://服务域名/v1`。程序会追加 `/chat/completions`。
- `AI_MODEL`：账号可用的模型 ID。
- `AI_API_KEY`：服务端密钥，请在本机设置。

修改后重新启动 `npm run dev` 或 `npm run preview`。两个本地服务均提供同源接口。仅发布 dist 时还需部署相应的服务端接口。AI 请求按服务商规则计费。未配置或请求失败时仍可使用课程参考解析。

## 巩固学习更新

- 移除学习分钟数、估算时长图表及固定两小时要求，学习步骤仅自主勾选完成项。
- 阅读选择题全部核对后，每题无论对错均显示课程解析和“AI 解析本题”按钮。按需点击调用已配置的 AI，不会在每次更换选项时自动产生请求。
- 词汇、每日填空和阅读题可收录到待复习本并直接重做。与填空参考不同不直接等同于语法错误，AI 判断为自然的阅读替代表达单独标为可用。
- 每课新增独立的换场景表达任务及自查提示，仅保存完成标记，不保存逐次回答。
- 课文按已收录词库做最长短语优先匹配，支持常见词形变化和部分代词分隔短语；采用当天课程释义。句前扬声器负责朗读/停止，查词不触发整句播放。未知或未收录的短语不保证自动识别。
- `npm run check:reinforcement` 检查短语匹配、迁移任务和 AI 接口协议。AI 协议使用本地模拟服务，不调用付费 API。

当前课程版本为 conversation-v2；详细课程表与验收结果见 [日常与通用职场对话主线更新](docs/conversation-course-update.md)。原技术词库、收藏及错题保留。改写后的前 30 课重新计算阅读和迁移任务完成情况，旧完成标记与旧笔记保留并与新课隔离，避免显示未学过的新内容已经完成。

## GitHub Pages 验收

推送到 `main` 后，GitHub Actions 的 `Build and deploy learning app` 工作流会安装依赖、核验课程、构建并发布 `dist`。首次使用需在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。

发布成功后可从 https://izeik.github.io/ 验收。仓库 Actions 页面可查看本次构建与部署结果。GitHub Pages 提供静态课程与练习；AI 解析仍需单独部署服务端接口，现有个人 API 密钥不会随前端构建上传。
